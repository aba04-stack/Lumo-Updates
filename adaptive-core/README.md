# Adaptive Core — безопасное адаптивное ядро

Экспериментальное ядро для систем, которые должны учиться на результате работы, выбирать более удачные стратегии и постепенно улучшаться без самоперезаписи исполняемого кода.

## Принцип

1. Система выбирает активную стратегию для класса задач.
2. Внешний исполнитель (модель или инструмент) выполняет задачу.
3. Результат оценивается и сохраняется в локальную SQLite-базу.
4. Выбор стратегии адаптируется по накопленной статистике.
5. Новая версия инструкции/настроек регистрируется отдельно как кандидат.
6. Кандидат и действующая стратегия сравниваются на одних и тех же тестовых примерах.
7. Продвижение разрешается только при минимальном улучшении и ограниченном регрессе. В противном случае действующая стратегия остаётся нетронутой.

## Защита от поломок

- Ядро не изменяет собственный Python-код и не исполняет код кандидата.
- Стратегии неизменяемы: каждое изменение получает новый ID и новую запись.
- Все данные сохраняются транзакционно в SQLite.
- Новая стратегия сначала проходит одинаковый набор оценочных примеров.
- Если оценщик падает, возвращает некорректный результат или проверки не пройдены, кандидат не активируется.
- Предыдущие активные стратегии сохраняются; новую можно отключить и вернуться к прежней.
- Результаты работы и решения о продвижении записываются в журнал событий.

## Что это умеет сейчас

Это инженерный каркас адаптации: долговременная память о результатах, выбор стратегий по накопленным оценкам, проверяемое продвижение кандидатов и откат. Для решения реальных задач нужен внешний исполнитель и надёжный оценщик. В v0.1 нет встроенной языковой модели и ядро само по себе не обучает веса нейросети.

Оценка кандидата настолько надёжна, насколько надёжен переданный оценщик. Для серьёзных задач используйте повторяемый тестовый набор, независимые метрики и скрытый контрольный набор, который не участвует в подборе стратегии.

## Запуск

Нужен Python 3.11 или новее.

Из корня репозитория установите пакет командой:

    python -m pip install -e "adaptive-core[dev]"

Запустите проверки:

    python -m pytest adaptive-core/tests -q

## Пример интеграции

Создайте Store, затем AdaptiveCore; зарегистрируйте baseline для типа задачи. Перед выполнением задачи вызовите choose_strategy(task_type), передайте возвращённую конфигурацию внешней модели, оцените ответ независимым оценщиком и сохраните результат через record_result. Новые инструкции добавляйте как candidate через Store.create_strategy и проверяйте EvolutionManager.evaluate_candidate.

Не передавайте результат самопроверки модели как единственный источник истины. Предпочтительны детерминированные тесты, запуск кода в изоляции, формальные проверки и независимая оценка.

## Ограничения

- Улучшение выбора стратегии не означает автоматического улучшения весов нейросети.
- Это не сознание и не доказательство сознания.
- Ядро не гарантирует отсутствия ошибок; оно уменьшает риск повреждения принятой конфигурации и помогает обнаруживать регрессии.
- Не подключайте к ядру неограниченный доступ к shell, секретам или продакшен-среде.
