# Adaptive Core — экспериментальная автономная когнитивная система

Исследовательский каркас без обязательной нейросети: долговременная память, символический вывод, обучаемая модель внутренних состояний и постоянные внутренние цели, которые влияют на выбор исследований.

## Архитектура v0.6

- **Stable Core** — версионированные стратегии, SQLite, журнал событий и сравнение кандидатов на одинаковых тестах.
- **Global Workspace** — ограниченное рабочее пространство с ранжированием сигналов.
- **Episodic Memory** — долговременные записи опыта с результатами и метаданными.
- **Internet Knowledge** — явный запрос к API Википедии; выдержки хранятся с URL, временем получения и SHA-256.
- **Affect Engine** — шесть внутренних управляющих состояний; веса модели изменяются по ошибке предсказания результата и сохраняются в SQLite.
- **Motivation Engine** — пять ограниченных внутренних оценок потребности: любопытство, компетентность, согласованность знаний, прогресс и снижение неопределённости. Давление потребностей меняется после результата; цели с названием, основанием, приоритетом, ведущим мотивом и статусом сохраняются и проходят жизненный цикл от очереди до выполнения/откладывания.
- **Reasoning Engine** — объяснимый вывод по явно заданным правилам, происхождение фактов и конфликты. Он не понимает произвольный текст как языковая модель.
- **Autonomous Learning Loop** — выбирает темы на основе приоритета, давления внутренних потребностей и текущих состояний; ищет ограниченное число страниц и учится на эвристической полезности поиска.
- **Evolution Manager** — принимает новые конфигурации стратегий лишь после оценки на общих тестовых примерах.

## Запуск

Требуется Python 3.11+ и доступ к интернету для новых запросов. Из каталога `adaptive-core`:

    python -m pip install -e ".[dev]"
    adaptive-research --steps 3 --page-budget 6

Можно задать темы явно:

    adaptive-research --topic "искусственный интеллект" --topic "эмоции" --steps 2 --page-budget 4

Состояние хранится в SQLite-файлах `adaptive-core.sqlite3` и `adaptive-web-knowledge.sqlite3`. Цикл исследования запускается командой и не начинает неограниченную фоновую работу сам по себе.

## Как работает мотивационный цикл

1. Система получает наблюдаемые сигналы результата: прогресс, новые термины, неопределённость и явно обнаруженные противоречия.
2. Давление внутренних потребностей изменяется на основании этих сигналов и постепенно возвращается к исходному уровню.
3. Каждая исследовательская тема представляется также постоянной целью с выбранным мотивом, приоритетом и статусом.
4. При выборе следующего шага цель оценивается по её приоритету и текущему давлению соответствующей потребности; обучаемые аффектоподобные состояния дополнительно модулируют выбор.
5. После шага результат, внутренние состояния и жизненный цикл цели сохраняются в событийном журнале.

Это простая вычислительная модель потребностей, не человеческая психология в полном смысле. Сигнал полезности поиска основан на количестве полученных страниц и новых терминов. Он не оценивает истинность утверждений или качество источников. Необнаруженное противоречие не считается обнаруженным автоматически.

## Обучение внутренних состояний и границы

Affect Engine — небольшой линейный онлайн-обучатель, а не языковая модель. Его признаки, названия состояний и начальные веса пока задаются разработчиком; наблюдаемые результаты меняют будущие реакции. Motivation Engine использует простые начальные правила обновления потребностей, а не обученную нейронную модель. Эти механизмы делают внутреннюю политику адаптивной, но не доказывают субъективные эмоции или сознание.

В проект не встроены самостоятельное переписывание Python-кода и неограниченный фоновый сбор данных. Кодовые изменения требуют отдельного тестирования и review.

## Проверки

    python -m pytest tests -q

Тесты используют фиктивные ответы сети. Они проверяют обновление и сохранение весов, давление потребностей, выбор мотивированных целей, жизненный цикл целей и регрессии. Прохождение тестов не доказывает истинность найденных материалов и наличие сознания.
