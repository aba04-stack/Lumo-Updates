# Adaptive Core — экспериментальная автономная когнитивная система

Исследовательский каркас без обязательной нейросети: долговременная память, эвристический поиск знаний в интернете, объяснимый символический вывод, внутренние аффектоподобные состояния и ограниченный цикл самостоятельного исследования.

## Архитектура v0.4

- **Stable Core** — неизменяемые версии стратегий, SQLite, журнал событий и проверка конфигураций.
- **Global Workspace** — ограниченное рабочее пространство, где сигналы ранжируются по приоритету и операционной оценке надёжности.
- **Episodic Memory** — постоянные краткие записи опыта с результатами, метками и метаданными.
- **Internet Knowledge** — явный запрос к открытому API Википедии; выдержки хранятся локально вместе с URL, временем получения и SHA-256.
- **Affect Engine** — состояния любопытства, удовлетворённости, фрустрации, осторожности, уверенности и вовлечённости. Они меняются от событий и влияют на выбор исследований. Это управляющие переменные, а не доказательство переживаемых чувств.
- **Reasoning Engine** — объяснимый вывод по заданным правилам, цепочка вывода, происхождение фактов и отображение противоречий. Он не понимает произвольный текст как языковая модель.
- **Autonomous Learning Loop** — выбирает тему с учётом очереди и состояний, ищет ограниченное число страниц, анализирует релевантные выдержки, предлагает новые темы и сохраняет результат цикла.
- **Evolution Manager** — принимает новые конфигурации стратегии только после сравнения на одних и тех же тестовых примерах.

## Запуск исследовательского цикла

Требуется Python 3.11+ и доступ к интернету для новых запросов. Установка из каталога adaptive-core:

    python -m pip install -e ".[dev]"

Запустить три ограниченных шага:

    adaptive-research --steps 3 --page-budget 6

Можно задать собственные темы:

    adaptive-research --topic "искусственный интеллект" --topic "эмоции" --steps 2 --page-budget 4

Состояние хранится в SQLite-файлах adaptive-core.sqlite3 и adaptive-web-knowledge.sqlite3. Сделайте резервную копию этих файлов, если в них накоплены важные записи. Цикл запускается командой и не начинает неограниченную фоновую работу сам по себе.

## Как устроен самостоятельный цикл

1. Выбирает непроверенную тему из постоянной очереди; повторные безрезультатные запросы ограничены.
2. Выполняет ограниченный поиск в Википедии и сохраняет ссылки на страницы.
3. Рассматривает фрагменты по пересечению ключевых слов и явно помечает их как непроверенные.
4. На основе новых материалов предлагает связанные темы для будущих циклов.
5. Вычисляет эвристическую полезность поиска по объёму материалов и новым терминам, сохраняет результат и меняет внутренние состояния.
6. Следующий выбор зависит от очереди и значений любопытства и фрустрации. Полезность поиска не является оценкой истинности утверждения.

## Рассуждение и проверка

Символический движок принимает явные факты и правила вида «если выполнены эти условия, вывести это заключение». Он записывает объяснение каждого вывода и не скрывает противоречивые факты. Текстовый обзор использует простую релевантность по ключевым словам; семантическое понимание, проверка истинности и причинное рассуждение здесь отсутствуют. Для перевода текста источника в формальные факты понадобится отдельный проверяемый извлекатель.

## Самоулучшение и границы

Система адаптирует исследовательское поведение: ведёт память, учится на измеренной полезности поисков и меняет приоритеты будущих тем. Это не обучение весов нейросети и не самостоятельное переписывание Python-кода. Кодовые изменения должны проходить отдельные тесты и review. В проект не встроена языковая модель, поэтому выводы ограничены явными правилами и эвристиками.

«Эмоции» — вычисляемые состояния, возникающие в ответ на успех, отсутствие результатов, неопределённость и противоречия. Они могут регулировать поведение, но проект не доказывает, что система субъективно что-либо чувствует или обладает сознанием.

## Проверки

    python -m pytest tests -q

Тесты не требуют интернета: сетевые ответы имитируются. Прохождение тестов не подтверждает истинность найденных в сети материалов и наличие сознания. Не подключайте неограниченный доступ к shell, секретам или производственной среде.
