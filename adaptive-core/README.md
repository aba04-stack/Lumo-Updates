# Adaptive Core — экспериментальная автономная когнитивная система

Исследовательский каркас без обязательной нейросети: долговременная память, эвристический поиск знаний в интернете, объяснимый символический вывод, обучаемая система оценок внутренних состояний и ограниченный цикл самостоятельного исследования.

## Архитектура v0.5

- **Stable Core** — версионированные стратегии, SQLite, журнал событий и проверка конфигураций.
- **Global Workspace** — ограниченное рабочее пространство, где сигналы ранжируются по приоритету и операционной оценке надёжности.
- **Episodic Memory** — постоянные краткие записи опыта с результатами, метками и метаданными.
- **Internet Knowledge** — явный запрос к открытому API Википедии; выдержки хранятся локально вместе с URL, временем получения и SHA-256.
- **Affect Engine** — шесть внутренних управляющих состояний: любопытство, удовлетворённость, фрустрация, осторожность, уверенность и вовлечённость. Начальные веса служат слабыми предположениями; наблюдаемые результаты изменяют связи между оценкой ситуации и будущими реакциями. Модель и счётчик обучающих примеров сохраняются в SQLite-журнале.
- **Reasoning Engine** — объяснимый вывод по заданным правилам, цепочка вывода, происхождение фактов и отображение противоречий. Он не понимает произвольный текст как языковая модель.
- **Autonomous Learning Loop** — выбирает тему с учётом очереди и внутренних состояний, ищет ограниченное число страниц, анализирует релевантные выдержки, предлагает новые темы и обучает модель оценок на измеренной полезности поиска.
- **Evolution Manager** — принимает новые конфигурации стратегии только после сравнения на одних и тех же тестовых примерах.

## Запуск исследовательского цикла

Требуется Python 3.11+ и доступ к интернету для новых запросов. Установка из каталога adaptive-core:

    python -m pip install -e ".[dev]"

Запустить три ограниченных шага:

    adaptive-research --steps 3 --page-budget 6

Можно задать собственные темы:

    adaptive-research --topic "искусственный интеллект" --topic "эмоции" --steps 2 --page-budget 4

Состояние хранится в SQLite-файлах adaptive-core.sqlite3 и adaptive-web-knowledge.sqlite3. Сделайте резервную копию этих файлов, если в них накоплены важные записи. Цикл запускается командой и не начинает неограниченную фоновую работу сам по себе.

## Как устроен самостоятельный цикл

1. Выбирает непроверенную тему из постоянной очереди; повторные безрезультатные запросы ограничены.
2. Выполняет ограниченный поиск в Википедии и сохраняет ссылки на страницы.
3. Рассматривает фрагменты по пересечению ключевых слов и явно помечает их как непроверенные.
4. На основе новых материалов предлагает связанные темы для будущих циклов.
5. Считает эвристическую полезность поиска по полученным страницам и новым терминам. Эта величина применяется как сигнал обучения, но не является оценкой истинности утверждений.
6. Обновляет веса модели оценок, сохраняя предсказанный результат, ошибку предсказания и число обучающих примеров; будущие реакции зависят от накопленных ассоциаций.

## Рассуждение и проверка

Символический движок принимает явные факты и правила вида «если выполнены эти условия, вывести это заключение». Он записывает объяснение каждого вывода и не скрывает противоречивые факты. Текстовый обзор использует простую релевантность по ключевым словам; семантическое понимание, проверка истинности и причинное рассуждение здесь отсутствуют. Для перевода текста источника в формальные факты понадобится отдельный проверяемый извлекатель.

## Обучение внутренних состояний: текущие границы

Affect Engine — небольшая модель с линейными весами и онлайн-обновлением по ошибке предсказания результата. Она действительно изменяет и сохраняет параметры на основе обратной связи; это следующий шаг относительно прежней таблицы фиксированных изменений состояний. При этом признаки ситуации и смысл отдельных управляющих состояний по-прежнему заданы человеком как начальные предположения. Это не обучение крупной языковой модели и не доказательство субъективных эмоций или сознания.

Текущая обратная связь автономного цикла отражает **полезность извлечения информации** — число найденных страниц и новых терминов. Она не оценивает истинность или качество источников, поэтому модель может научиться успешнее искать материалы, но не может из одного этого сигнала узнать, истинны ли их утверждения.

Самоизменение Python-кода не включено. Изменения кода должны проходить тесты и review; экспериментальные параметры модели хранятся отдельно от исполняемого кода.

## Проверки

    python -m pytest tests -q

Тесты не требуют интернета: сетевые ответы имитируются. Они проверяют сохранение и обновление весов, границы состояний, рассуждение и поведение цикла. Прохождение тестов не подтверждает истинность найденных материалов и наличие сознания.
